# デザインの正本は独立リポジトリ nozomiishii/design に置く

Status: accepted
Date: 2026-07-24

## Context — 判断を迫られた状況

複数プロジェクトにデザインシステムを導入するにあたり、統一と差分の境界を検討した。Apple / Google / Spotify の調査から、プリミティブトークンは全共有、セマンティックトークンは名前だけ共有して値は各プロジェクトで上書きする層構造(Spotify Encore の system of systems 型)を採ることにした。トークンの試作は [nozomiishii/dev#2995](https://github.com/nozomiishii/dev/pull/2995) で dev 内に作ったが、どのプロジェクトにも属さない共有物のため置き場が問題になった。

## Decision — 決めたこと

- デザイントークンの正本を独立リポジトリ nozomiishii/design に置き、configs と同じ npm 配布モデル(@nozomiishii/*)で各プロジェクトへ配る
- リポジトリは公開にする。条件: 再配布できない有償フォントを置かない、ロゴなどブランド資産を置かない、未公開プロダクトの画面やストーリーは各プロジェクト側(private)に置く
- コンポーネント共有(ui パッケージ)はトークン運用が回ってから判断する

## Consequences — 決定がもたらすもの

- 各プロジェクトはセマンティックトークンの値だけ上書きすれば、レイアウトと操作を共有したままブランドを分けられる
- 公開リポジトリのため GitHub Actions が無料になり、Storybook 等の公開ホスティングも使える
- 移植の実装は [#1](https://github.com/nozomiishii/design/pull/1) を参照
